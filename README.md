## Как обновить (через GitHub Desktop)
1. Claude правит файлы в этой папке.
2. Открываю GitHub Desktop: слева видно, что изменилось.
3. Внизу слева пишу коротко, что поменял (Summary), жму **Commit to main**.
4. Жму **Push origin** сверху. Через 1–3 минуты сайт обновится.
