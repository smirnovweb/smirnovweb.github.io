## Как обновить (через GitHub Desktop)
Эта папка — копия репозитория `smirnovweb.github.io`, связанная с GitHub.
1. Claude правит файлы в этой папке.
2. Я открываю GitHub Desktop: слева видно, что изменилось.
3. Внизу слева пишу коротко, что поменял (Summary), жму **Commit to main**.
4. Жму **Push origin** сверху. Через 1–3 минуты сайт обновится.

`README.md` (этот файл) лежит в репозитории, но на сайте не показывается — это настроено в `_config.yml`.
