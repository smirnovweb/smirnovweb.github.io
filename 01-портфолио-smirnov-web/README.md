## Как обновить
1. Claude правит `index.html` (и картинки в `images/`) в этой папке.
2. Я загружаю на GitHub: репозиторий → Add file → Upload files → перетащить `index.html` и папку `images` → Commit changes.
3. Через 1–3 минуты сайт обновится.
